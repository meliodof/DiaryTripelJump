# Исследование аналитических моделей

Скрипты, которыми подобраны и проверены модели из `data/Insights.kt`. Сырые данные в репозиторий не кладутся: их можно скачать заново сборщиками.

| Скрипт | Что делает |
|---|---|
| `tfrrs_collect.py <папка> <лимит> <номера профилей через запятую \| refetch>` | Собирает истории стартов в тройном (а также длине, высоте и шесте) у спортсменов NCAA с tfrrs.org. Между запросами пауза. |
| `wa_collect.py <папка>` | Профили из топ-листов World Athletics: дата рождения, лучший результат по сезонам, старты текущего сезона. |
| `gc_collect.py <папка> <N>` | GoldenCheetah OpenData (osf.io/6hfpz). Из каждого журнала оставляет только сводку по тренировкам. |
| `evaluate.py <wa> <tfrrs> <out.json>` | Сравнивает модели прогноза. Включает признаки из литературы и проверку прироста по возрасту. |
| `holt.py`, `ses_break.py` | Подбирают вес сглаживания, проверяют тренд Холта и вес после межсезонья. |
| `gc_analyze.py <gc> <out.json>` | Модель связей приложения и модель «форма — усталость» на журналах велосипедистов. |
| `assistant/train.py <app/src/main/resources/ai> results/assistant_eval.json <app/src/test/resources/ai>` | Обучает свои модели помощника на `assistant/dataset.py`: тип вопроса и метки заметок. Выгружает веса в приложение и контрольные пары для теста. |
| `assistant/check_exported.py <app/src/main/resources/ai>` | Проверяет выгруженные модели на фразах из тестов. |
| `gen_ai_doc.py <out.docx> results/eval_all.json results/gc_result.json results/assistant_eval.json` | Собирает документ `D:\диплом\ИИ_исследования_ДневникТройного.docx`. |

В `results/` лежат итоговые цифры. В них только агрегаты, без имён спортсменов.
